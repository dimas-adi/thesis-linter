# Core Engine Review

Scope: `src/main.rs`, `src/config.rs`, `src/linter.rs`, `src/structure.rs`, `src/fixer.rs`, `src/report.rs`, and their tests. Review date: 2026-11-05.

Method: a throwaway harness outside the repo drove the real `docx-lint` binaries against synthetic documents. Each "Measured" proof is the observed result of such a run. "Reasoned" means not measured.

**Verdict:** not acceptable as is. `--fix` can destroy the owner's input, and a text box or an equation makes the linter and the fixer act on the wrong paragraphs or write invalid XML. Most of these defects share one root cause: three separate XML walkers (Q16). Fix the behavior first, pin it with tests, then merge the walkers.

## Checked, no finding
- **R-002:** every error path measured exits 2, except the panics in S7: missing file, unknown subcommand, missing profile, bad output directory, and each `config` error.
- **R-004, R-005:** JSON has the contract fields with and without `--fix`. One document produced all nine codes, and the source holds no other code literal.
- **R-006, base case:** empty `<w:p/>` is counted and margins report 0. Nested paragraphs fail (Q1, Q2).
- **R-011:** a stored binary, an empty entry, a directory entry, a CRLF part, and a `../../evil.txt` entry name all survive with identical content, and nothing is written outside the output file.
- **R-020:** `auto` and absent `lineRule` are checked; `exact` and `atLeast` are not.
- **R-021:** `Heading*` and `Title` skip the size check and keep the font check. `TitleX` and `Subtitle` get both. Nested paragraphs fail (Q1).
- **R-028:** dotted, spaced-dot, `…`, trailing-number, and tab-plus-`PAGEREF` contents lines are not headings.
- **R-039:** `0`, `false`, and single-quoted `'0'` count as not italic in the linter and the fixer.
- **R-044, R-046, R-048:** the schema loads with the same values, including an integer `top_cm`, a BOM, and an unknown extra key. `--profiles-dir` works before and after the subcommand and creates no `./profiles`. The report has no `http`, `src=`, `href=`, or `url(`, and hostile font text stays escaped.
- **R-009, partly:** non-zip, 0-byte, no `document.xml`, directory-only, mismatched tags, non-UTF-8, UTF-16, bzip2, and encrypted inputs all exit 2. 800 mutation runs on the debug build (400 on zip bytes, 400 on XML text) gave no panic. 200,000 nested tables pass in 0.17 s. A DOCTYPE entity is never expanded.
- **Reserved names:** `CON` and `NUL` create ordinary `CON.toml` and `NUL.toml` on this Windows 11 host.

## Owner decisions inside Phase 3
Each default below is already written into a Phase 3 task. Change the task before running Phase 3 if you disagree.
- **New direct dependency (T3.1):** `same-file` 1.0, already in `Cargo.lock`. It is the only measured check that also catches a hard link, because stable `std` has no file identity on Windows.
- **Stricter `config init` (T3.17):** D-001 freezes R-040. Refusing to overwrite a profile keeps what that rule says, but it is a visible CLI change.
- **Stricter profile loading (T3.15):** a hand-edited profile with a value outside the schema now exits 2 instead of loading.
- **Size limit (T3.6):** `word/document.xml` over 64 MiB is an error. The 30k-paragraph test document was 8 MB.
