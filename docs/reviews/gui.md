# GUI Review

Scope: `src/gui.rs` and `tests/gui_state.rs`. Review date: 2026-11-05.

Method: a throwaway crate outside the repo drove the real `DocxLintApp` against synthetic documents, and rendered the real `eframe::App::ui` panels headlessly at fixed screen sizes. Each "Measured" proof is the observed result of such a run. "Reasoned" means not measured. Real windows, native dialogs, and real Word stay under H-GUI and H-WORD.

**Verdict:** not acceptable as is. Export HTML can destroy the owner's thesis, and it can report `No violations found.` for a file that failed to load. A saved profile is not used after a restart. The core guards exist but the GUI does not reach them, because each guard sits in the caller instead of the operation: `ensure_distinct` guards `--html` only in `main.rs`, and `validate` runs only on save. Move each guard into the shared operation so a caller cannot skip it.

## Checked, no finding
- **R-010, Auto-Fix:** the same path, `./in.docx`, `.\in.docx`, `IN.DOCX`, `sub/../in.docx`, and a hard link each give an `Error` status and identical input bytes. Export HTML fails (S1).
- **R-049, R-050, R-052 (persist and re-lint), R-053, R-054, R-055:** behavior matches the rule. Non-zip, 0-byte, no `document.xml`, and malformed inputs each set an `Error` status with no violations and no panic.
- **R-051, behavior:** a document with all nine codes gives 14 violations and 14 across Layout, Structure, and Academic, with each code in one tab. Only the test is weak (Q8).
- **R-056, base case:** replacing a dictionary word keeps a term that is only in the profile. The overlap case fails (Q4).
- **R-042 through the Name box:** an empty name, `a/b`, `..`, and `C:evil` each give an `Error` status and create no file.
- **Locked outputs:** Auto-Fix and Export HTML to a file opened with no sharing each give an `Error` status, and no temp file remains.
- **SPEC GUI logic rule:** every action is a public method with no `egui` type. The private `pick_*` methods only open a dialog and delegate.
- **File size:** `src/gui.rs` is 399 lines. Splitting state from panels would not remove any concept, so no decomposition is proposed.
- **Dialog extension (Reasoned, from `rfd` 0.17.2 source):** the first filter becomes the default extension, so a typed `foo` saves as `foo.docx`.
- **Working directory after a dialog (Reasoned):** `rfd` sets no options on file dialogs, so the system default, documented to include `FOS_NOCHANGEDIR`, stays. `./profiles` should stay put. H-GUI can confirm this by checking that the profile list is unchanged after an Open dialog.
